# KEEP MARKET — правила для разработки

- Владелец не программист: объяснять по-русски, по шагам, без командной строки.
- **Позиционирование (обязательно):** магазин продаёт собственный товар. В любых текстах для покупателя
  (витрина, оформление, заказ, бот, уведомления, история статусов) не упоминать поставщиков, дропшиппинг,
  «уточнение наличия у поставщика». Внутренние разделы админки (поставщики, прайсы, закупка) — можно.
- Путь заказа: new «Ожидает подтверждения менеджера» → checking_availability «Проверка наличия» →
  awaiting_payment «Ожидает оплату» → awaiting_shipment «Ожидает отправку» → shipped «Отправлено» → delivered.
  Матрица переходов в `supabase/functions/_shared/domain/orders.ts` должна совпадать с `order_transition_allowed()`.
- Наши расходы (закупка, курьер — `order_logistics_costs`) покупателю не видны: не добавлять их в таблицы,
  которые покупатель читает целиком (`orders`, `shipments`).
- Остаток по умолчанию у новых размеров — 3 шт.
- Сервер обновляется сам после push (workflow «Supabase: обновить базу и функции»).
- Перед коммитом: `npm test` и `npm run typecheck`.
