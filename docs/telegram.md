# Telegram: бот, Mini App, уведомления

## 1. Бот

1. @BotFather → `/newbot` → имя «KEEP MARKET», username, например `keepmarket_shop_bot`. Токен — **только** в секреты
   Supabase (`TELEGRAM_BOT_TOKEN`), никогда во frontend и репозиторий.
2. Для разработки создайте отдельного тестового бота.

## 2. Mini App

1. @BotFather → `/newapp` → выберите бота → URL: адрес GitHub Pages, например `https://tsaga7.github.io/KEEP-MARKET/`,
   short name, например `shop`. Укажите его в секрете `TELEGRAM_APP_SHORT_NAME`.
   Прямая ссылка на магазин: `https://t.me/<бот>/shop`; на товар: `https://t.me/<бот>/shop?startapp=p_<slug с _ вместо ->`.
2. Настройте webhook, кнопку меню и команды:

```bash
TELEGRAM_BOT_TOKEN=... TELEGRAM_WEBHOOK_SECRET=... \
SUPABASE_URL=https://<ref>.supabase.co APP_PUBLIC_URL=https://tsaga7.github.io/KEEP-MARKET/ \
npm run telegram:setup
```

3. Кнопка в канале: добавьте бота администратором канала и опубликуйте пост с inline-кнопкой-ссылкой
   `https://t.me/<бот>/shop` (кнопки `web_app` в каналах не поддерживаются — используется прямая ссылка Mini App).
4. В админке → Настройки укажите `telegram_bot_username`, `telegram_channel_url`, `manager_contact_url`.

## 3. Чат менеджеров

1. Создайте **закрытую** группу сотрудников, добавьте бота.
2. Узнайте `chat_id` группы (например, переслав сообщение группы боту @getidsbot или из логов функции) и укажите его
   владельцем в настройке `manager_chat_id` (формат `-100…`).
3. В группу приходят: новые заявки (номер, количество, сумма, кнопка «Открыть заявку»), подтверждения/отмены
   покупателей, сообщения покупателей из бота. ФИО, телефоны и адреса в чат **не отправляются**.
4. Ответ покупателю: reply на пересланное сообщение. Ответить может только сотрудник с ролью в админке.

## 4. Авторизация

- Mini App передаёт исходную строку `initData` в `auth-telegram`; функция проверяет HMAC-подпись токеном бота,
  `auth_date` (по умолчанию не старше 24 ч — `INIT_DATA_MAX_AGE_SECONDS`) и наличие пользователя.
- Вне Telegram авторизация невозможна: каталог доступен как гостю, заказы/избранное — нет (показывается понятная ошибка).
- Админ-панель открывается внутри Telegram (в том числе Telegram Desktop): «Профиль → Панель управления» или ссылка
  из уведомления о заявке.

## 5. Личные уведомления

Бот может писать покупателю только после того, как покупатель сам открыл бота (`/start` или переход по ссылке
после оформления заявки). До этого уведомления не отправляются, статус заказа виден в «Мои заказы».
