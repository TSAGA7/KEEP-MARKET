# Владелец, сотрудники, работа в админ-панели

## Создание владельца (один раз)

Владелец не может быть назначен через интерфейс или API. Порядок:

1. Откройте Mini App в Telegram со своего аккаунта — создастся профиль.
2. Узнайте свой Telegram ID (например, @userinfobot).
3. В Supabase → SQL Editor (выполняется с правами postgres):

```sql
select public.bootstrap_owner(123456789);
```

Функция сработает, только если владельца ещё нет. Повторный вызов вернёт `OWNER_ALREADY_EXISTS`.
Передача владения — только вручную в базе с записью в `audit_logs`; через интерфейс не предусмотрена.

## Сотрудники

Админка → Настройки → Сотрудники: введите @username или Telegram ID человека, который уже открывал магазин,
выберите роль. Владелец назначает администраторов и менеджеров, администратор — только менеджеров.
Нельзя менять собственные роли и роль владельца.

## Ежедневная работа менеджера

1. **Обзор** → «Новые заявки».
2. Карточка заявки → «Начать проверку наличия» → связаться с поставщиком.
3. «Зафиксировать результат проверки»: по каждой позиции — в наличии / нет / замена / ожидание; при изменении цены
   обязательно указать причину; указать стоимость доставки и срок. Если условия менялись, покупатель получит
   запрос подтверждения. Если всё уже согласовано в чате — отметьте это галочкой.
4. «Согласовать способ оплаты». Для онлайн-оплаты покупатель увидит кнопку «Оплатить онлайн».
5. «Передать поставщику» → блок «Передача поставщику» формирует минимальный текст (состав + данные для отправки).
6. «Готов к отправке» → «Отправить и внести трек-номер» → «Отметить доставку».
7. Офлайн-оплату (перевод, при получении) фиксирует владелец/администратор кнопкой «Зафиксировать полученную оплату».

## Остатки

«Размеры и остатки» → «Требуют подтверждения»: остаток, не подтверждённый дольше `stock_freshness_hours`, показывается
покупателю как «Наличие уточняется». Подтверждение пишется в журнал.

## Прайсы поставщиков

«Прайсы» → поставщик → CSV (`;` или `,`, UTF-8). Колонки: артикул поставщика, цена (до 2 знаков, `1 200,50`),
остаток (целое), необязательно — название, размеры и цвета через `|`. Шаблон: `public/supplier-price-template.csv`.
Сервер проверяет каждую строку → отчёт → «Применить» → при ошибке «Отменить импорт» восстанавливает прежние значения.
Новые артикулы создаются без привязки — привяжите их к вариантам в «Поставщики → Предложения».

## Товары

«Товары → Добавить товар» → черновик → фото (порядок стрелками, первое — обложка), варианты (сочетания цветов и
размеров), закупочная цена → «Отправить на проверку» → владелец проводит проверку в «Проверка ассортимента» →
«Опубликовать». Кнопка публикации показывает, чего не хватает.
