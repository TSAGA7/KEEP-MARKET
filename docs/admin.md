# Владелец, сотрудники, работа в админ-панели

## Создание владельца (один раз)

Владелец не может быть назначен через интерфейс или API. Порядок:

1. Откройте Mini App в Telegram со своего аккаунта — создастся профиль.
2. Узнайте свой Telegram ID (например, @userinfobot).
3. В Supabase → SQL Editor (выполняется с правами postgres):

```sql
select public.bootstrap_owner(123456789);
```

Функция сработает, только если владельца ещё нет. Повторный вызов вернёт `OWNER_ALREADY_EXISTS`.
Передача владения — только вручную в базе с записью в `audit_logs`; через интерфейс не предусмотрена.

## Сотрудники

Админка → Настройки → Сотрудники: введите @username или Telegram ID человека, который уже открывал магазин,
выберите роль. Владелец назначает администраторов и менеджеров, администратор — только менеджеров.
Нельзя менять собственные роли и роль владельца.

## Ежедневная работа менеджера

Путь заказа: **Ожидает подтверждения менеджера → Проверка наличия → Ожидает оплату → Ожидает отправку → Отправлено → Доставлено**
(отдельно — «Отменено» и «Проблема»).

1. **Обзор** → «Новые заявки».
2. Карточка заявки → «Начать проверку наличия».
3. «В наличии → ожидает оплату»: по каждой позиции — в наличии / нет / замена / ожидание (не отмеченные считаются в наличии);
   при изменении цены указать причину; при необходимости — стоимость доставки для покупателя и срок.
4. «Способ оплаты». Для онлайн-оплаты покупатель увидит кнопку «Оплатить онлайн».
5. Когда деньги пришли — «Оплачено → ожидает отправку» (или «Зафиксировать полученную оплату»: статус сменится сам).
6. «Отправить»: перевозчик, трек-номер (необязательно) и наши расходы на курьера (необязательно) → «Отметить доставку».
7. Расходы на курьера можно поменять в карточке заявки; их видят только владелец и администраторы,
   в «Обзоре» они вычитаются из разницы с закупкой.

**Позиционирование:** магазин продаёт собственный товар. Покупателю нигде не сообщается о поставщиках и их
проверке — ни в магазине, ни в боте, ни в ответах менеджера. Откуда товар — коммерческая тайна.

## Остатки

Остаток задаётся прямо в карточке товара (таблица «Размеры и варианты»). Новые размеры получают 3 шт.
Пока остаток больше нуля, покупатель видит «В наличии» — без срока давности.

## Прайсы поставщиков

«Прайсы» → поставщик → CSV (`;` или `,`, UTF-8). Колонки: артикул поставщика, цена (до 2 знаков, `1 200,50`),
остаток (целое), необязательно — название, размеры и цвета через `|`. Шаблон: `public/supplier-price-template.csv`.
Сервер проверяет каждую строку → отчёт → «Применить» → при ошибке «Отменить импорт» восстанавливает прежние значения.
Новые артикулы создаются без привязки — привяжите их к вариантам в «Поставщики → Предложения».

## Товары

«Товары → Добавить товар» → черновик → фото (порядок стрелками, первое — обложка), варианты (сочетания цветов и
размеров), цена → «Опубликовать». Для публикации нужны категория, цена, хотя бы одно фото и один вариант;
описание и артикул необязательны. Если чего-то не хватает, карточка покажет список.

## Импорт товаров из канала поставщика

1. Перешлите пост поставщика (одно фото или альбом с подписью) в личный чат с ботом. Импорт доступен владельцу и администраторам.
2. Бот создаёт **черновик**: название — первая строка подписи, описание — остальной текст без контактов поставщика (ссылок, @username, телефонов, хэштегов). Полный текст поста сохраняется во внутренних заметках.
3. Цена из поста по умолчанию записывается как **закупочная** (настройка `import_price_mode`). Если задать `import_markup_percent`, розничная цена посчитается автоматически с округлением до 10 ₽.
4. Найденные размеры становятся вариантами с остатком 0. Наличие нужно уточнить у поставщика.
5. Поставщик определяется автоматически, если в его карточке указан Telegram-канал.
6. Фото сохраняются в оригинале и ставятся в очередь на удаление фона. GitHub Actions «Фото: удаление фона» проверяет очередь каждые ~10 минут. Коллажи и крупные планы остаются как есть. В карточке товара можно переключиться между версиями «без фона» и «оригинал» или запустить обработку заново.
7. Проверьте карточку (цена, категория, остатки) и опубликуйте товар.

Артикул товара и вариантов необязателен: если поле пустое, магазин присваивает `KM-000123` и `KM-000123-0001`.
